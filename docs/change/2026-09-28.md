## 23:45 · 修复 · v0.4.2 日志双通道收口（法器/坊市分类恒空 + 上限 200）

- **范围**：通用引擎 / docs
- **摘要**：日志页「奇遇 / 法器 / 坊市」三个分类一条信息都没有，排查结论——
  1. **法器 / 坊市：实装缺陷（分类恒空）**。日志是**双通道**——`H.pushLog(ws, msg, tag)` 才落盘进日志页，`res_push` 仅作瞬时 toast。而法器（`dropGear` / `recheckStash`）与坊市（`shopTick` / `shopRefresh` / `buyGoods`）**全程只走 `res_push`**、从不 `pushLog`，故这两类**永远为空**（不是「没发生」，是「没记账」）。
  2. **奇遇：记账正常，但稀疏**。`fireEvent` / `resolveChoice` 均有 `pushLog(…, 'event')`；但 `eventTick` 触发概率与时长成正比（`p = min(0.95, 0.10 × 小时数 × (1+奇遇频率))`），在线连续游玩（每秒 tick）`p ≈ 2.8e-5` 几乎不触发，奇遇实际只发生在**离线大间隔（>60s）回归**时。叠加 `H.pushLog` 上限仅 50 条，低频条目易被高频条目（功法 / 系统）挤出窗口 → **属正常稀疏 + 窗口过小，非缺陷**。
- **修复**：
  - `engine.js`：`dropGear`（换装 / 境界不足入库藏阁 / 库藏阁溢出炼化）、`recheckStash`（境界复检自动装备）补 `H.pushLog(…, 'gear')`；`shopTick`（补货上新）、`shopRefresh`（手动刷新）、`buyGoods`（购入法器 / 丹药 / 功法 / 法宝 / 灵石包）补 `H.pushLog(…, 'shop')`。**纯「不合用炼化」不落日志**（高频噪声）；`res_push` 瞬时提示保持不变。
  - `core.js`：`H.pushLog` 上限 **50 → 200**。
