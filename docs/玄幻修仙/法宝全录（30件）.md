## 一、系统定位：法宝 ≠ 法器装备

**现状问题**：当前四槽（兵刃 / 法宝珠 / 甲衣 / 佩饰）本质是**法器装备**——批量掉落、随机词条（atk / qiBonus / resist / attrValue）、自动择优炼化，是纯数值养成。把它叫「法宝」名不副实。

**本卷方案**：

| 层 | 旧称呼 | 新称呼 | 逻辑 |
|---|---|---|---|
| 四槽随机装备 | 法宝 | **法器** | 词表 `gear.system` 由「法宝」改为「法器」，槽位名不变；批量、随机、择优、炼化的逻辑**完全不动** |
| 新增灵宝系统 | — | **法宝** | 独立栏位、唯一性、签名效果、获取门槛——本文档定义 |

> **兼容**：存档 `worlds.xiuxian.gear`（四槽法器）字段零改动；法宝走新增字段 `treasures`，`normalize` 缺省为空。

**法宝三条设计铁律**：

1. **一件一效果**：每件法宝只带 **1 条签名效果**，且 30 条互不重复、不与法器特殊词条池（剑魄 / 聚灵纹 / 疾影…）语义重叠；
2. **效果机制化**：签名效果优先落在**新机制 / 主动触发 / 条件联动**上，而非又一条 +X% 被动（被动数值交给法器词条与功法）；
3. **门槛换强度**：先天法宝强度显著高于法器词条，但用**高境界 + 属性 + 善恶阵营**三重门槛 + 代价换，不破坏既有乘区预算。

## 二、法宝分类与规则

### 2.1 先天法宝 vs 后天法宝

| 维度 | 先天法宝（12 件） | 后天法宝（18 件） |
|---|---|---|
| 来源 | 天地初开、混沌交感自然孕育 | 修士以灵材炼制 |
| 数量 | **全局唯一**，每件仅一件 | 可重复获得（同名同效，可祭炼） |
| 成长 | **认主度**（1→3 阶，靠机缘阶跃，不可用灵石买） | **祭炼等级**（1→5 级，消耗灵石 + 材料） |
| 品阶 | 不设凡/良/上/灵/仙，走「先天·上/中/下品」稀有档 | 沿用五品阶（凡/良/上/灵/仙） |
| 门槛 | 高（境界 3~7 + 属性 + 阵营） | 中低（境界 0~4） |
| 强度 | 强，带明确代价 | 中，纯增益可叠加 |
| 获取 | 秘境首通 / 渡劫奖励 / 稀有奇遇 / 黑市绝版 | 坊市 / 秘境掉落 / 奇遇 / 炼器 |

### 2.2 栏位与装备规则

- **法宝栏 3 格**：第 1 格 **练气**解锁、第 2 格 **金丹**解锁、第 3 格 **化神**解锁；
- 先天 / 后天**共用**栏位，无类型限制；
- **唯一性**：同一件法宝不可重复装备（先天全局唯一；后天同名视为同一件，祭炼等级取高者）；
- 法宝**不参与**法器自动择优、不炼化、不占库藏阁；卸下即回法宝库（无容量上限）；
- 法宝**不提供** atk / resist 等法器词条，只提供签名效果——**避免与法器双吃战力**。

### 2.3 成长：认主 / 祭炼

| 成长 | 机制 | 提升方式 | 上限 |
|---|---|---|---|
| 认主度（先天） | 效果按阶跃提升（如 +X% → +1.5X% → +2X%） | 渡劫成功累计 / karma 达档 / 对应秘境首通 三选一达成即 +1 阶 | 3 阶 |
| 祭炼等级（后天） | 主效果按等级阶梯提升 | 消耗灵石（随等级递增）+ 对应品阶灵材；祭炼失败 30% 降 1 级 | 5 级 |

> 祭炼失败降级是**灵石水槽**（与炼化、商店同层），不进「不可逆损失」红线。

### 2.4 使用要求三要素

法宝的 `reqs` 引用与功法同款结构，判定只读**当前值**（穿脱法器/功法会即时影响达标）：

```
reqs: { realm?: number, attr?: {id:'jing'|'qi'|'shen', min:number}, karmaMax?: number, karmaMin?: number }
```

未达标：不可装备，法宝库中显示红字要求（「需境界：化神 / 神 ≥ 24 / 恶名 ≤ -200」）。

### 3.2 先天法宝（12 件 · 天地所生 · 全局唯一）

#### X01 鸿蒙紫气
- **类别**：先天 · 上品 ｜ **出处意象**：混沌初分时逸散的一缕本源之气
- **使用要求**：境界 ≥ 化神(4) ＋ 精 / 气 / 神 各 ≥ 30
- **签名效果**：**气运补偿**——任意随机判定（奇遇触发、掉落品阶、属性 check、渡劫）失败时，同类判定累计 **+2%**，可叠至 **+20%**；一旦成功立即清零。认主度每阶上限 +10pp。
- **挂点**：`on_reroll_fail`（新增）→ 写入 `treasures.fateStack`（按判定类别分桶）
- **获取**：界外古道首通 / 真仙渡劫奖励
- **备注**：唯一"元成长"型法宝，越挫越强，反哺渡劫苦渡玩家。

#### X02 太初青莲
- **类别**：先天 · 中品 ｜ **出处意象**：混沌青莲遗种，落地生根
- **使用要求**：境界 ≥ 筑基(1)
- **签名效果**：**生长**——在线挂机每累计满 1 小时，`qiRate` **永久 +0.5%**，上限 **+25%**；转世后清零（与转世循环呼应）。
- **挂点**：`on_tick_idle`（成长型）
- **获取**：黑风寨首通（低门槛早鸟法宝）
- **备注**：门槛最低的先天法宝，鼓励挂机长线。

#### X03 玄黄宝塔
- **类别**：先天 · 上品 ｜ **出处意象**：天地玄黄二气凝成，镇地承天
- **使用要求**：境界 ≥ 元婴(3) ＋ 神 ≥ 24
- **签名效果**：**渡劫护体**——渡劫失败时灵气损失**固定为 30%**（替代基准半损 ± 天赋/神修正）；每承受一次失败，塔身积威，下次渡劫 **+3%** 成功率（上限 +15%，成功后清零）。
- **挂点**：`on_trib_fail`（改写损失公式 + 累积 next 加成）
- **获取**：焦土遗迹首通
- **备注**：把"渡劫失败"从惩罚转为可累积的资源。

#### X04 两仪太极图
- **类别**：先天 · 上品 ｜ **出处意象**：阴阳二气所化，包罗万象
- **使用要求**：境界 ≥ 化神(4)
- **签名效果**：**化解**——负面奇遇有 **50%** 概率被"化"为中性事件（不结算负面效果）；成功化解时 karma 归中 +5。战斗遇瓶颈时战力 **+20%**。
- **挂点**：`on_negative_event` ＋ `on_bottleneck`
- **获取**：乱星秘窟首通 / 稀有奇遇「太极遗图」
- **备注**：攻守兼备的"稳"型法宝，契合正道。

#### X05 开天神斧
- **类别**：先天 · 极品 ｜ **出处意象**：开天辟地之器
- **使用要求**：境界 ≥ 大乘(7) ＋ 精 ≥ 48
- **签名效果**：**开天一击**——战斗中 **10%** 概率秒杀当前秘境首领（立即 +20 杀进度，等效通关提速）；代价：每次触发后 **30 分钟** `combatPower −10%`（斧势泄尽）。
- **挂点**：`on_kill_crit`（新增）
- **获取**：天渊龙墟首通 / 混沌雷海
- **备注**：唯一"爆发换持续"的高风险法宝，高境界专属。

#### X06 镇天混沌钟
- **类别**：先天 · 上品 ｜ **出处意象**：镇压时空之钟
- **使用要求**：境界 ≥ 炼虚(5)
- **签名效果**：**时空**——离线结算上限 **+6 小时**，且离线收益按 **120% 效率**结算；在线挂机每 10 分钟获得 1 次"时空加速"（下一次击杀进度 **+5**）。

#### X07 诛仙剑阵图

#### X08 山河社稷图

- **使用要求**：境界 ≥ 元婴(3) ＋ 气 ≥ 24

- **使用要求**：境界 ≥ 化神(4) ＋ 精气神各 ≥ 24
- **签名效果**：**悟道**——功法修炼速度 **+50%**；功法学习要求（属性 / karma 门槛）**−20%**；待修习架容量 **24 → 36**。

#### X11 阴阳乾坤鼎
- **类别**：先天 · 上品 ｜ **出处意象**：炼化万物之鼎
- **使用要求**：境界 ≥ 炼虚(5)
- **签名效果**：**造化**——可在法宝界面将 **灵气 1:1 无损转化为灵石**（打通两大货币），或将 **100 灵石炼成 1 枚聚灵丹**（`qiRate +50%`，持续 1 小时）。
- **挂点**：`on_convert`（新增，法宝界面主动操作）
- **获取**：天渊龙墟 / 坊市绝版
- **备注**：唯一"资源转化"型法宝，给后期灵石水槽一个出口。

#### X12 九幽血莲
- **类别**：先天 · 上品 ｜ **出处意象**：幽冥血海孕育之莲
- **使用要求**：境界 ≥ 元婴(3) ＋ karma ≤ −500（魔道）
- **签名效果**：**堕落**——击杀妖怪获得灵石 **+40%**；但每在线挂机 1 小时 **karma −2**（持续堕落）；当 karma ≤ −800 时，战斗速度 **+30%**。
- **挂点**：`on_kill_stones` ＋ `on_karma_tick`（新增）
- **获取**：黑市绝版 / 魔道专属奇遇
- **备注**：魔道"快但险"的极致——越堕越强，但锁死渡劫成功率（karmaMod 负档）。
