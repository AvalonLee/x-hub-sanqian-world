## 五、世界名命名池（registry.nameParts）

```
prefix: 玄 青 紫 太 九 沧 天 罗 幽
middle: 云 霄 虚 阳 冥 岚 岳
suffix: 界 境 天 域 洲
```

样例：青云界 · 太虚境 · 九霄天。创角屏 3 生成一次，固定写入 `profile.worldName`。

### 5.1 法宝命名池（P4 登记）

装备 `item.name` 生成规则：**材质 × 器形** 两段拼接（与品阶无关，品阶走角标/词表 `gear.tier.N`）：

```
材质: 玄铁 寒铜 青冥 紫霄 星辰 流光 墨玉 赤阳 幽银 龙虎
器形: 兵刃 → 剑 / 法宝 → 珠 / 甲衣 → 甲 / 佩饰 → 佩
```

样例：玄铁剑 · 青冥珠 · 星辰甲 · 墨玉佩（40 组合，同槽可重名，重名不影响择优——score 说了算）。

## 六、初始参数（initialState 摘要）

- 灵气 0 / 灵石 100（新手启动资金）/ 境界 0（练气）；
- 初始功法：吐纳法 + 聚灵诀（黄字阶左道双功法，见功法全录）；
- karma 0 / attrs 全 0 / tribulation 与 stash、formation 等专属字段按工程规范 §3.3 缺省。
