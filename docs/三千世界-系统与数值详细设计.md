## 一、G2 主资源挂机（修为）

> **命名**：主资源内部字段 `qi`，**UI 显示名「修为」**（修仙世界）。世界包 `lexicon.resource.primary` 当前仍写「灵气」，属待统一项（工程规范 §一 / §八偏差登记）——本文正文一律用「修为」，历史段落中的「灵气」同义。

### 1.1 双状态（v0.3.0）

修仙世界有两个挂机状态，随时可切换（`ws.mode`）：

| 状态 | `mode` | 修为/灵蕴产出 | 战斗 | 定位 |
|---|---|---|---|---|
| 打坐修炼 | `'cultivate'` | **×2** | 不推进秘境 | 闭关攒修为、冲突破 |
| 秘境历练 | `'combat'` | ×1 | 推进秘境击杀 | 刷装备、刷灵石 |

### 1.2 产出公式

```
每秒修为产出 = 境界基础产出 × (1 + Σ qiRate 加成) × 阵营修炼倍率 × 状态倍率 × 顿悟倍率
```

- **境界基础产出**：见 §六境界表 `baseQi` 列；
- **阵营修炼倍率**（善恶系统联动）：正道 `0.9` / 左道 `1.0` / 魔道 `1.2`，按当前 karma 区间实时取（karma 跨过分界线的瞬间切换，无缓冲）；
- **状态倍率**：打坐 `2` / 历练 `1`；
- **顿悟倍率**：顿悟 buff 生效期间 `2`，否则 `1`（见 §1.5）；
- **buff 倍率**：奇遇限时 buff 与 debuff 的乘积。

### 1.3 积累上限（qiCap）

```
修为上限 = max( baseQi × 7200 秒 , 下一阶突破 need × 1.15 ) × (1 + Σ qiCap 加成)
```

- 上限永远高于突破阈值 15%（复核修订：**旧式「纯 2 小时产出」会封死化神以后的所有突破**，见复核报告问题 1）；
- **渡劫为确认制（v0.3.0 起）**：修为攒满即**封顶等待**（`qi` 自然停在 `qiCap`），玩家点「渡劫突破」才掷判——上限因此是**常态可见的天花板**，提醒玩家「该突破了」；
- 真仙（无下一阶）后上限回落为 2 小时产出量，到顶显示「已臻化境」；
- `qiCap` 加成乘区（天赋/聚灵诀/聚灵阵盘等）作用于整个 max 结果。

### 1.4 离线结算

- **离线效率基准 50%**：离线期间按 `每秒产出 × (0.5 + Σ offlineEff 加成)` 计算；
- **离线时长上限 12 小时**：`capH = 12 + Σ on_offline_cap_h`（法宝/功法可延长，如 X06 镇天混沌钟 +6h、h03 御风灵舟 +3~5h、长夜修行 +1~3h），超出部分不计（未来可留「鸿蒙大世界云补偿」钩子，本期不做）；
- **离线不掷渡劫**（确认制）：离线期间只结算修为/灵蕴产出、事件（单次 claim ≤3 条）、商店补货，修为到上限即停，等玩家回来确认；
- `iter` 上限 64 兜底，防止极端时间差导致死循环（防改系统时间作弊面）；
- 结算完成后写一条汇总日志：「闭关 X 小时 Y 分，得修为 N」。

### 1.5 灵蕴（lingyun，第二副资源 · v0.3.0）

**灵蕴**是功法升级的唯一货币（§4.2），随时间自动积累：

```
灵蕴速率 = (1 + 境界索引 × 2) × 状态倍率(打坐 ×2) × 顿悟倍率(×2)
离线按 (0.5 + Σ offlineEff) 折算
```

- 打坐 + 顿悟叠加时最高 ×4，鼓励「闭关」；
- 奇遇/丹药可额外给予灵蕴（事件 `fx.lingyun`）；
- **顿悟（epiphany）**：打坐状态下随机触发（每秒概率 `dt/1000 × 0.004`，期望约每 4 分钟一次），持续 90 秒，期间修为与灵蕴产出 **×2**；buff 字段 `{ field:'epiphany', until }`；
- **打坐领悟**：打坐状态下小概率（`COMPREHEND_CHANCE = 0.0015`/秒）领悟当前境界可学的未持有功法（`tryComprehend`），是功法收集的被动补充来源。

### 1.6 修为用途（资源水槽）

| 用途 | 出口 |
|---|---|
| 渡劫突破 | 修为 ≥ 突破需求时点「渡劫突破」按钮确认（主文档 §七） |
| 渡劫失败损耗 | 失败修为 ×(1 − 损失系数)，基准半损 0.5（受 tribFailLossFactor 修正，clamp [0.3, 0.7]） |
| 奇遇事件 | 部分事件按 qiPct 增减 |
| 丹药/灵石包 | 商店部分商品以修为计价（见 §五） |

> **货币分工**：灵石（stones）是主货币——法器炼化、法宝祭炼/购买、商店购物的出口；灵蕴（lingyun）是功法升级的专用货币（§4.2）。

## 二、G3 战斗历练（秘境）

### 2.1 核心循环

```
选择秘境 → 按战斗速度持续击杀 → prog 0→100 → 通关：掉装备 + 解锁下一秘境
```

- **击杀节奏（实装口径）**：基础击杀间隔 `interval = 10000 ms / (1 + Σ combatSpeed)`——基准速度 **1 次/10 秒 = 360 杀/小时**（`combatSpeed` 乘区越大间隔越短）；**战斗只随在线 tick 推进，离线期间不模拟秘境**（决策：离线收益聚焦挂机修为，秘境刷取是在线玩法）。
  > **勘误**：v1.6 曾把节奏改写为「60 杀/小时（1 次/60 秒）」，但实装 `engine.js` 为 `10000ms` 基准（= 360 杀/小时），且 §6.4/§九 的经济测算（zone9 约 540 万灵石/小时 = 15,000 × 360）本就是按 360 杀/小时算的——故「60 杀/小时」系 v1.6 引入的孤立错误，此处回写为实装值 360 杀/小时，与代码及经济测算对齐。
- **单杀进度**：每次击杀 `prog +5`（20 杀通关）；通关后 `prog` 清零，转为可重复刷取模式（重复刷只掉装备/灵石，不再解锁）；瓶颈状态下 `prog` 封顶 90；
- **单杀收益**：灵石 = 秘境表 `spk` × (1 + Σ stonesRate)；每次击杀按 §2.3 掷掉落。

### 2.2 瓶颈机制

```
当前战力 < 秘境需求战力 → 击杀间隔 ×3，且 prog 封顶 90（无法通关）
```

- UI 在秘境入口显示红字「修为不足，举步维艰」，并给出建议（换装备 / 升功法 / 先渡劫）；
- 瓶颈惩罚修正：精属性 ≥ 中等 dc 时惩罚由 ×3 降为 ×2（`interval /= 6`）；功法「御风」挂点 `on_bottleneck_interval` 再 ×0.8；法宝/装备「尸傀护主」类挂点 `on_bottleneck_power` 在瓶颈时额外抬战力；
- **战力公式**：

```
战力 = (境界基础战力 + Σ 法器 atk) × (1 + Σ combatPower 加成)
```

### 2.3 掉落规则

- **单次击杀掉落率**：基准 `8% × (1 + Σ dropRate)`；另有挂点 `on_kill_drop`（枯木逢春等）追加一次独立掷骰；
- **品阶权重**：按秘境索引查掉落表（§六），索引越高稀有度重心越靠上；
- **通关必掉**：prog 满 100 时必掉 1 件装备，品阶权重整体上浮（首通 `zoneBoost=1`，重复通关 `zoneBoost=0.5`）；
- **秘境首通赠先天法宝**（v0.4.0）：黑风寨→X02、万兽谷→X08、焦土遗迹→X03、雷池禁地→X09、乱星秘窟→X04、修罗战场→X06、天渊龙墟→X05、界外古道→X01（详见《法宝全录（30件）》§五）；
- **魔道专属掉落**：法宝 X07 诛仙剑阵图每累计 100 杀额外掉 1 件魔道法器；
- 掉落即进入 G4 自动择优流程，玩家无感知（只弹 toast：「拾得 玄铁剑（良品）→ 已替换 / 已炼化 +60 灵石」）。

### 2.4 秘境切换

- 同一时间只有一个「进行中秘境」；切换秘境不损失 prog（各秘境 prog 分别存档）；
- 已通关秘境可回访刷取（收益不变），未解锁秘境显示剪影 + 解锁条件。

## 三、G4 装备（法器）

> **命名**：四槽随机装备统一称「**法器**」（G4）。「法宝」一词自 v0.4.0 起专指独立收集系统「法宝（灵宝）」，见 §十 / 主文档 §七·补。

### 3.1 槽位（4 槽）

| 槽位 | 修仙词表 | 主词条侧重 |
|---|---|---|
| weapon | 兵刃 | atk |
| treasure | 宝珠 | qiBonus |
| armor | 甲衣 | atk / resist |
| accessory | 佩饰 | resist / qiBonus |

### 3.2 品阶（5 阶）与词条池

品阶从低到高：**凡品 → 良品 → 上品 → 灵品 → 仙品**。词条随品阶递进解锁（主文档 §7.6 已定）：

| 品阶 | atk | qiBonus | resist | 词条基础区间 |
|---|---|---|---|---|
| 凡品 | ✅ | — | — | atk 2~5 |
| 良品 | ✅ | ✅ | — | atk 4~8，qiBonus 3%~8% |
| 上品 | ✅ | ✅ | ✅ | atk 8~14，qiBonus 8%~15%，resist 40~80 |
| 灵品 | ✅ | ✅ | ✅ | atk 14~24，qiBonus 15%~25%，resist 80~150 |
| 仙品 | ✅ | ✅ | ✅ | atk 22~36，qiBonus 25%~40%，resist 150~260 |

> **缩放规则（复核修订，见复核报告问题 2/4）**：
> - `atk 实际值 = atk 基础区间随机 × max( P[掉落秘境解锁境界] / 100 , 1 )`——与境界基础战力指数挂钩（旧的线性 ×(1+索引×0.35) 跟不上境界 ×3 增长，会导致后期秘境数学上不可达）；
> - **qiBonus（百分比）不随秘境缩放**，固定区间——百分比若参与缩放，后期单件可破 130%，击穿乘区体系；
> - **resist 不随秘境缩放**，固定区间——它喂给有封顶的渡劫公式（满仙品 Σ≈1,040，resist 项 ≈0.17，永远拿不满 0.20 上限，留追求空间）；
> - **attrValue（属性亲和，第四词条）灵品起解锁**，不随秘境缩放：灵品 8~14 / 仙品 15~25，单属性随机（精/气/神），槽位亲和权重与判定机制见《角色属性设计》§3.3。词条解锁阶梯更新为：凡 1 / 良 2 / 上 3 / **灵·仙 4**。

### 3.3 阵营（alignment）分布

- 掉落时掷阵营：**左道 60% / 正道 25% / 魔道 15%**；
- 魔道装备词条数值 **×1.10**（补偿 karma 代价：每件 -15）；正道装备 ×1.00；左道 ×1.00；
- 商店与奇遇 `dropGear{alignment:'evil'}` 可定向产出魔道装备（如「魔道密使」事件）。

### 3.4 评分与自动择优

```
评分 score = ( atk + qiBonus×100 + resist×0.5 + attrValue×3 ) × 特殊词条系数
特殊词条系数 = 带 special 时 1.15，否则 1.0（特殊词条价值 ≈ 半条主词条，P5 复核）
```

（score 仅用于自动择优的 **同槽比较**，不再参与经济结算——见下方炼化修订）

- **要求前置检查**：拾取/购买装备先过佩戴要求（§3.5）——不满足者**不参与择优比较**，直接入库藏阁（见下）；
- **自动替换**：满足要求的新装备 score > 当前槽位 score → 自动装备，旧件自动炼化；
- **库藏阁（stash）**：不满足要求的装备自动入库暂存，**基础容量 12 件**（`12 + Σ on_stash_cap`，法宝 X08/h04、乾坤袋可扩容）；每次境界提升后自动复检，达标即参与择优；库满时自动炼化其中 score 最低者（写日志）；
- **自动炼化（复核修订，见复核报告问题 3）**：返还为 **品阶固定表 × (1 + 境界索引 × 0.5) × (1 + Σ on_refine)**：

| 品阶 | 凡品 | 良品 | 上品 | 灵品 | 仙品 |
|---|---|---|---|---|---|
| 返还基数（灵石） | 5 | 20 | 100 | 500 | 2,500 |

  旧的 `score × 品阶系数` 公式会让后期单件炼化返还 ≈ 1 小时刷图收入（掉落 ~29 件/小时 → 通胀 20 倍），已废弃；
- 无手动锁定功能（本期不做，保持全自动的省心定位）；
- 每次替换/炼化/入库写日志，玩家可在日志栏回溯。

### 3.5 佩戴要求（按价值而定）

装备要求 = **品阶基础境界** + **极品词条追加**，两层叠加：

| 品阶 | 基础佩戴境界 |
|---|---|
| 凡品 / 良品 | 无要求 |
| 上品 | 金丹（境界 2） |
| 灵品 | 化神（境界 4） |
| 仙品 | 合体（境界 6） |

- **极品词条追加（神兵认主）**：`resist` 或 `attrValue` roll 到区间 **前 10%** 的高价值装备，佩戴境界 **+1 阶**——价值越高要求越高；
- 特殊词条**不**追加要求（避免与「无视佩戴要求」词条自我矛盾）；
- 未达标装备在 UI 显示红字要求（「需境界：化神」），入库藏阁等待；
- **设计意图**：低境界刷到仙品不再是「即刻战力」而是「存起来的盼头」，给秘境刷取加一条长线钩子；同时压住前期跳级配装对瓶颈机制（§2.2）的击穿。

### 3.6 装备特殊词条（special，随机低概率）

上品及以上装备掉落/购买时掷一次特殊词条：

| 品阶 | 附带概率 |
|---|---|
| 凡品 / 良品 | 0%（不携带） |
| 上品 | 3% |
| 灵品 | 8% |
| 仙品 | 15% |

每件至多 1 条特殊词条，从下池**按权重抽取**（`gearSpecialList`，非等权；「无视佩戴要求」权重略高——它只对本就有要求的装备生效，实际有效率低）：

| id | 名称 | 效果 | 权重 |
|---|---|---|---|
| `ignore_req` | **无视佩戴要求** | 该装备的佩戴要求（含极品追加）全部无效，拾取即可择优佩戴 | 12 |
| `sword_heart` | 剑魄 | combatPower +8% | 9 |
| `spirit_rune` | 聚灵纹 | qiRate +8% | 9 |
| `adamantine` | 金刚质 | resist +60（加在词条之上） | 9 |
| `swift_shadow` | 疾影 | combatSpeed +10% | 9 |
| `merchant_wit` | 商慧 | shopCost -8% | 9 |
| `karma_mirror` | 照业镜 | eventLuck +12% | 9 |
| `dao_oath` | 道侣之约 | offlineEff +12% | 9 |
| `thunder_mark` | 雷纹 | 渡劫 +5%（挂点 `on_trib_flat`，与天赋 tribBonus 同区） | 8 |
| `devour` | 噬灵 | 击杀灵石 +12%（挂点 `on_kill_stones`） | 8 |

- 特殊词条效果进入对应乘区/挂点（§八总表登记为「装备特殊词条」来源），数值幅度 ≈ 半条主词条——**低概率补偿高价值**；
- 带特殊词条的装备在 UI 上加暗金角标 + 词条名，炼化/替换日志中注明（防玩家没看见好东西被自动炼化——入库藏阁与炼化日志必须带 special 标记）；
- 存档结构：**法器** item 字段为 `{ slot, tier, name, alignment, atk, qiBonus?, resist?, attrValue?, reqs, special }`，其中 `reqs: { realm }` 与 `special: string|null` 在生成时定格；**功法** item 为 `{ id, name, alignment, attr, fx, special, reqs, price, srcShop }`（`artsKnown/shelf` 元素为 id，属性查世界包数据表）；**法宝** item 为 `{ id, lv }`（后天）或 `{ id, stage }`（先天）。字段全量登记见工程规范存档字段总表。

## 四、G5 技能（功法）

### 4.1 结构

- **6 个修习槽位** + **待修习架（shelf）**——功法全录扩容至 51 部后容纳收集玩法；**容量 24 已强制**（v0.4.1）：`gainArt` 入库前判 `shelf.length < 24`，满则按「重复所得」口径自动转灵石并写日志，不再无限堆积；
- 功法可自由装入/移出槽位（无冷却无成本），只有槽内功法生效；
- **功法等级渡劫成功后全部保留，不清零**（v0.3.0 变更，主文档 §7.3）：旧设计「渡劫成功功法清零重修」已废弃，改为渡劫成功触发「天道垂青」三选一天赋作为正反馈；
- 功法来源：坊市购买（正道/左道走正常页签、魔道走黑市）、秘境首通、奇遇掉落、**打坐领悟**（`COMPREHEND_CHANCE` 每秒 0.0015）与**击杀掉残页**（`ART_DROP_CHANCE` 每次击杀 0.003）。

### 4.2 升级消耗（灵蕴）

### 4.6 散功（功法处置 · v0.4.1）

> 动机：功法池 51 部 + 掉落/领悟/购买三渠道，低阶（黄/玄字阶）功法随游戏推进只会越攒越多，而修习槽只有 6 个——低阶功法既不上场、又占列表。本机制给玩家一个**主动清理出口**，并把「功法堆叠」从纯收藏转为可管理资产。

- **可散功对象**：`artsKnown` 中**未装入任何槽位**、且**非初始自带**（`tuna` / `juling`，散功后 `normalize` 会强制补回并丢等级，故禁止）的功法；
- **待修习架（shelf）**条目走同口径的「**弃置**」（未修习，`lv = 0`）；
- **散功返还（灵石）** = `ceil( base × (1 + 修习等级 × 0.25) )`：

  | 情形 | base 取值 |
  |---|---|
  | 坊市可售（`price > 0`） | `price × 0.4` |
  | 非卖品（秘境首通 / 奇遇限定，`price = 0`） | 按品阶基数表：黄 120 / 玄 400 / 地 1,500 / 天 6,000 |

- **防套利约束**：可售功法返还系数 **0.4 < 重复所得系数 0.5**，故「买入 → 散功」恒为亏损，不存在灵石套利回路；非卖品按品阶定额，避免 0 价导致零返还；
- **等级补偿**：`(1 + lv × 0.25)` 让已投入灵蕴的功法不至于「散了个寂寞」（Lv5 返还 ×2）；
- **无冷却、无成本**；散功后该功法从 `artsKnown` 移除、`artsLevels` 键删除，并整体 `recalcDerived`（karma / attrs 覆盖式重算，不会残留）；
- 散功**不影响**已获得的收集进度以外的任何系统；被散功的功法日后仍可再次掉落/购买（回到未持有状态）；
- **写日志**：`散功《{名}》，化灵石 {N}`（`tag: 'skill'`）。

### 6.3 战力/渡劫联动核对表（P5 复查用）

```
p = clamp( base(realm) + resist项 + 战力项 + talentBonus + karmaMod + treBonus + nextBonus, 0.05, 0.95 )
  talentBonus = Σ天赋 tribBonus + 挂点 on_trib_flat（雷纹等）
  treBonus    = 法宝 X01 气运补偿(≤0.20+0.10×(阶−1)) + X03 塔身积威(≤0.15)
  nextBonus   = tribNext（破障丹 / 吃一堑 / 养魂木，掷判后清空）
```

| 场景 | 预期 |
|---|---|
| 练气→筑基（base 0.95） | 裸身也能过，失败仅损失前期微量修为，教学局 |
| 化神→炼虚（base 0.70） | 无 resist 法器时约 7 成成功率，日均 1~2 次失败可接受 |
| 渡劫→真仙（base 0.45） | 满配：resist 项 ≈0.17 + 战力项 0.15 + 雷灵根 0.15 + karma ≥800 的 0.20 + 法宝（X01/X03）→ p 封顶 0.95；裸身 p = 0.45 苦渡（期望尝试 2.2 次） |

## 十、法宝（灵宝）系统（v0.4.0）

> 数据与运行时实装于 [`assets/worlds/xiuxian/treasures.js`](../assets/worlds/xiuxian/treasures.js)；30 件全表见 [`玄幻修仙/法宝全录（30件）.md`](./玄幻修仙/法宝全录（30件）.md)；系统定位与渡劫衔接见主文档 §七·补。

### 10.1 结构

- **30 件固定法宝**，全局唯一；与四槽法器（`ws.gear`）**完全独立**——法宝无 `atk/resist` 词条，只带签名效果；
- **先天 12 件**（`kind:'xian'`）：认主阶 1~3，唯一；**后天 18 件**（`kind:'hou'`）：祭炼等级 1~5；
- **3 栏位**（`treasures.slots`）：练气(0) / 金丹(2) / 化神(4) 解锁（`SLOT_UNLOCK = [0,2,4]`）；
- **获得唯一入口** `grant(ws, id)`：已持有不重复给；来源 = 秘境首通 / 渡劫奖励 / 坊市 / 黑市绝版 / 奇遇。

### 10.2 成长与插值

```
scaled 键值域 [v1, vmax]：
  后天 lv(1..5)   → 现值 = v1 + (vmax−v1) × (lv−1)/4
  先天 stage(1..3)→ 现值 = v1 + (vmax−v1) × (stage−1)/2
  键前缀 'mult:xxx' → 进 zoneSum（同乘区加算）
  键前缀 'hook:xxx' → 进 hooks（挂点加算）
```

- **祭炼（后天）**：`refineCost = round(400 × 2.2^(lv−1) × (1 + 境界索引 × 0.4))` 灵石，lv5 封顶；
- **认主（先天）**：每阶需累计 **2 次渡劫成功**（全局 `tribWins`，`BOND_COST = 2`）。

### 10.3 签名效果分类

| 类别 | 机制 | 代表 |
|---|---|---|
| 纯乘区 | `mult:` 键 → `zoneSum` | h01 聚灵玉髓瓶 qiRate、h14 聚宝金盆 stonesRate、X10 造化玉牒 artsSpeed |
| 纯挂点 | `hook:` 键 → `hooks` | h15 养魂木 on_trib_next、h09 引魂铃 on_check、h18 锁灵环 on_lockling |
| 条件型 | 读 `ws.karma` 动态判定 | X12 九幽血莲 combatSpeed +30%（仅 karma ≤ −800）；X04 负面奇遇 50% 化解 |
| 动态累计 | 存 `treasures.*`，不入 `scaled` | X02 太初青莲（在线每满 1h qiRate +0.5%，上限 +25%，存 `x02Bonus`） |
| 特殊脚本 | `special:` 由 `SQXT` 特判 | X01 气运补偿、X03 渡劫护体、X05 开天一击、X07 杀伐、X09 续命、X11 阴阳转化、X12 堕落 |

### 10.4 与渡劫/战斗的数值衔接

- **渡劫加成**：X01 气运补偿 `fate`（失败 +2%/次，上限 `0.20+0.10×(阶−1)`，成功清零）+ X03 塔身积威 `towerStack`（每败 +3%，上限 +15%，成功清零）；
- **失败豁免**：X09 补天五色石每境界一次，失败不计 `attempts` 且损失减半（`budouRealm`）；
- **战斗挂钩**：X05 开天一击（击杀 10% 概率 prog +20，代价战力 −10%/30min）、X07 诛仙剑阵（每 100 杀掉 1 件魔道法器）、h18 锁灵（概率该杀灵石 ×5）、h17 化血神刀（每杀业力 −1）；
- **法宝售价**（坊市）：`ceil( 品阶基数 × (1 + 境界索引 × 0.4) × max(0.5, Σ shopCost) )`，品阶基数：良品 800 / 上品 2,000 / 灵品 3,500 / 灵品·魔道 4,200 / 仙品 12,000 / 先天·中品 15,000 / 先天·上品 30,000 / 先天·极品 60,000。

### 10.5 存档字段（`ws.treasures`）

```js
{ owned: [ {id,lv}|{id,stage} ], slots: [id|null,id|null,id|null],
  x02Bonus, onlineMs, x07Count, karmaAccMs,   // 动态累计
  fate, towerStack, tribWins, h10cd, budouRealm }  // 渡劫/条件态
```

- `normalize`：缺省补齐；`owned` 清洗非法 id，按 `kind` 规范化为 `{lv}` 或 `{stage}`；`slots` 内引用必须已持有，否则置 null。
