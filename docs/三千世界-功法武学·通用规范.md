## 一、品阶体系（两世界通用）

功法/武学按价值分四品阶，**学习要求随品阶递进**（落实「根据价值而定」）：

| 品阶 | 主效果/级 | 学习要求带 | 获取渠道 | 定位 |
|---|---|---|---|---|
| 黄字阶 | 3~5% | 无要求 ~ 界位 1 + 无属性门槛 | 商店低价 / 初始 | 前期过渡与字段补齐 |
| 玄字阶 | 5~7% | 界位 1~2 + 属性 ≥12~18；邪派 恶名 ≤-100~-120 | 商店中价 / 低区首通 | 中期主力 |
| 地字阶 | 7~10% | 界位 3~4 + 属性 ≥24~30；邪派 恶名 ≤-180~-200 | 商店高价 / 中区首通 / 奇遇 | 后期核心 |
| 天字阶 | 9~14%（tribBonus/gateMod 类例外：0.015~0.025/级） | 界位 5~8 + 属性 ≥36~54；邪派 恶名 ≤-300~-500 | 高区首通 / 稀有奇遇 / 黑市高价 | 终局追求，渡劫清零后的长线重修目标 |

- **属性门槛 = 对应界位裸身基础值**（(界位索引+1)×6，详设 §4.4 规律）——养成玩家可提前一界学会，裸身玩家界位达标即学会，永不死锁；
- 阵营分布目标（每世界）：正 ≈19 / 中立 ≈18 / 邪 ≈14——邪派单部效果 ×1.5 但总数少、门槛深，维持「快但险」；
- **数值预算（P5 审计修订版）**：同乘区功法层**期望合计（典型双修 Lv3）≤ +80%**（实测最大 combatPower 78% ✓）；**极限 6 槽满级逐字段审计上限**：combatPower +300% / qiRate +275% / offlineEff +230% / combatSpeed +195% / qiCap +175% / stonesRate +170% / artsSpeed +80% / eventLuck +85% / eventRate +65% / dropRate +45% / tribBonus +33% / realmCost −10%（原「极限 ≤+120%」与天字阶 9~14%/级 ×5 级 ×6 槽的数学上限矛盾，修订为逐字段审计值——超出即词条漂移，验收 #105 同口径）。极限单字段 build ≈ ×3.75 产出 → 真仙 13.3d→约 8d，与魔道速通同带；且渡劫清零后 6 部满级单字段重修成本极高，作为长线极限目标可接受；
